# ADR 0037: Authenticated local research workspace

2026-11-03 · Module 14 Iteration 1 · Accepted

Fastify exposes a separately authenticated, paginated operations API over semantically
verified paper/evaluation artifacts. Next.js consumes Zod-validated responses. UI state
does not execute strategies or value portfolios. Virtual amounts are labelled SIMULATED.
The signal drawer binds source hashes, cutoff, regime, calibration, risk, fills and net
return. Unattached producer vectors and source content remain explicitly unavailable.

Four API acceptance tests, strict frontend/backend typechecks, production Webpack build
and browser evidence trace passed. Ports 3100/3101 avoid the foundation service. Next's
automatic AGENTS generation is disabled; bundled versioned documentation was consulted.
This is a repository-local dashboard, with no Sites hosting or publication.
