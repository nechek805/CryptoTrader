# ADR 0036: Four-arm memo and immutable evidence bundles

Status: Accepted. Date: 2026-11-03. Scope: Module 13 Iteration 3.

Publish exact inputs, four-arm metrics, paired differences, frozen stresses, attribution,
calibration/timing limits and Continue/Revise/Stop criteria as an immutable artifact.
Reconstruct accepted source state for benchmarks/coverage. Quarantined or legally invalid
quotes cannot become passive prices. Link exact decisions, signals, fills, market evidence
and external source references. Missing original content remains visibly unattached.

Semantic verification rebuilds every byte. Keep negative/inconclusive runs searchable.
A profitable one-tail-event toy remains REVISE; the adverse-gap/license fixture retains
losses and STOP. No report establishes alpha or authorizes trading.

Acceptance: typecheck and 15 metrics/statistics/report tests pass. Both CLI bundles verify
and remain searchable. Report/plan schemas hand off to Modules 14–15.
