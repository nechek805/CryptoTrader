# News replay, explanations and incremental-value checks

Module 10 Iteration 3 completes the news-research handoff. Structured explanations bind
observed claims, independently attributed roots, opposing/retracted evidence, receipt
and publication clocks, event age, historical comparison, assumed costs and decision
reasons to immutable candidate/prefix hashes. Default experiments and clocks are entirely
synthetic. Execution and promotion remain disabled.

## Commands

Use pinned Node 24.22.2 / pnpm 10.34.9 from README.md:

```sh
pnpm news-audit fixture --out data/news-audit
pnpm news-audit verify --directory <printed-bundle>
pnpm news-audit report --directory <printed-bundle>
pnpm news-audit run --input <bundle>/input.json --out data/news-audit-built
pnpm news-audit reproduce --directory <bundle> --out data/news-audit-reproduced
```

`fixture` builds source-backed adversarial cases and a separate later evaluation cohort.
`run` accepts strict `news-audit-input.v1` JSON with an already frozen model. Verification
rebuilds source semantics, every decision/explanation, markout, comparison, journal and
archive. Reproduction preserves the stored software version. There are no credentials,
arbitrary fetches, live execution, publishing or promotion options.

## Explanations and source safety

`explainNewsSignal` regenerates a canonical conservative or estimated provider decision
before producing `news-explanation.v1`. Estimated explanations require matching admission
configuration. `explainNewsDecision` grounds an already computed producer result in its
semantically verified prefix; it is a description, not an authorization or independent
proof that arbitrary supplied decisions were generated by a producer. Durable bundles
receive full producer replay verification.

Each explanation contains the original quoted graph claims and their polarity, activity,
retraction, source role, origin basis and timing. Independent source IDs come only from
the opinion's representative roots. Opposing/uncertain assertions and retractions remain
visible rather than being overwritten. Receipt rows preserve article version, source
fingerprint, canonical URL, first observation, effective publication, graph availability,
extraction hash and review reasons. Publication time cannot substitute for receipt time.

The historical comparison is either explicitly UNTRAINED_RULE or the frozen model's
conditional mean, interval, TRAIN/VALIDATION sample and block counts, vintage and support
grade. Earlier untrained rule fixtures never receive future fitted estimates. Assumed
round-trip costs and uncertainty buffer are explicit. Stops and fill prices are null;
event-truth probability and return calibration remain absent.
Untrained directional rules explicitly report unknown return edge; they do not claim
that an estimated cost hurdle was passed. Only fitted candidates can clear cost gates.

Quoted source strings are untrusted data and never become prompts, configuration,
commands, paths or tool calls. Recognized instruction-like text is quarantined by the
existing extractor before producing claims. Source text is never evaluated, even if a
pattern guard misses novel wording. Markdown escapes HTML, code, links, images, table
separators and line breaks in source quotations. Raw machine-readable quotes preserve
the original evidence and must also be treated as untrusted by consumers.

The ten synthetic rule cases cover confirmation, official-looking rumor, rescission,
ten dependent copies, unknown availability, stale data, scheduled matching quantities,
instruction injection, altered publication time and a later independent denial.
An earlier SHORT can become a later HOLD; future denial/retraction cannot rewrite earlier
candidate identities or explanations. Altered timestamps are not repaired into eligibility.

## Frozen later evaluation

The evaluation plan is declared after model availability but before its TEST range.
The default model retains six TRAIN and three VALIDATION first-seen events per taxonomy.
TEST contains six later dates for each of two assets, January 28 through February 7, 2026. Every model-fit cutoff precedes TEST; full source and price provenance remain in
the input. Fictional declared clocks do not prove authentic preregistration.

The complete opportunity-ID set, horizon, cost, baselines, unit minimum and bootstrap
recipe are frozen. The runner requires all and only those observed TEST opportunities
and rejects duplicate event/time slots, caller-supplied admission state, changed horizons,
wrong snapshot/event/symbol bindings and costs below the model's floor. TRAIN/VALIDATION
lineage and original price IDs cannot reappear as TEST labels. Provider state survives
compatible source-history updates; TEST never selects, refits or changes model parameters.

The news producer reads only its model, as-of news snapshot and separate operational
freshness receipt. Future prices enter only the evaluator. All three controls use the
same declared symbol/time/horizon grid and common measurable coverage:

- News: zero for HOLD; otherwise signed forward price return less assumed round-trip cost.
- Cash: zero markout on the same measured opportunity set.
- Always-long: forward asset price return less the same assumed round-trip cost.

Cash and always-long decision rules read no news. The shared grid is news-conditioned;
this is not an unconditional market opportunity set or a continuously invested buy-and-hold
portfolio. These are paired price markouts, not simulated fills, executable short sales,
account equity, drawdown or net ledger PnL. Entry/exit prices, spread/depth and inventory
are not reconstructed into guaranteed trades. Module 08 execution formats remain unchanged.

Outcomes use Module 06's exact-close price availability gate. Late, missing, stale or
descriptive prices leave all paired values null. Unreliable news availability also leaves
the opportunity unmeasured. Reports retain every opportunity and show measured coverage;
missing outcomes never become zero returns. Missing common coverage disables intervals.

False positives are directional candidates with nonpositive signed net markout. Missed
events are HOLD decisions followed by a positive net move in the fixed TRAIN-selected
reference direction. True positives and correct abstentions are retained too. These are
hindsight price classifications, never truth labels or reasons to override conservative
abstention. Already-priced-in fixture news has a large pre-news move and no post-news edge;
the price-independent producer can still emit a candidate, honestly retained as a false
positive rather than receiving an invented live price feature.

## Paired uncertainty and negative results

Connected UTC days, event lineage, overlapping outcome windows and shared original bars
form sampling units. Within each unit, paired news-minus-control deltas are averaged;
units then receive equal weight. Two assets on one date do not become two independent
dates. With enough units and complete common coverage, seeded block resampling produces
two-sided percentile intervals for the two fixed baseline comparisons. The nominal
Bonferroni family is two, each level is 0.975 and tail index is
`floor((resamples-1)/80)`. This does not prove independence, causal identification,
population coverage or protection against unreported strategy searches.

The default run retains 192 explained decisions, including 180 rule replay decisions
and 12 held-out opportunities. It produces four false positives and six missed-event
cases across six date blocks. Mean news-minus-cash markout is approximately -0.00083333;
news-minus-always-long is approximately +0.00016667. Both conditional intervals cross zero.
Negative/inconclusive evidence is retained. The assessment is SYNTHETIC_ONLY, with no
real historical incremental-edge or profitability claim. All defaults are diagnostic.

## Durable evidence and Module 11 handoff

Bundles contain `input.json`, `report.json`, `report.md`, `decisions.jsonl`,
`extractions.json`, `handoff.json`, all unique prefix `snapshots/<hash>.json` and indexed
`bundle.json`. A decision hash chain includes explanations, not just directions. The
runner finishes before publication; files are synced in guarded staging directories and
published by atomic directory rename. Immutable reuse checks all existing bytes. Semantic
verification rejects forged explanations, markouts, archives and reports even if their
file checksums are repaired. Hashes prove content identity, not source authenticity.

The extraction archive deduplicates each exact extraction result and records article and
source IDs, input hash, model/prompt versions, prompt hash, exact known prompt text and
cost per article. Unknown prompt text or external cost stays unknown. The default's 108
extractions use the literal grammar with zero external cost and a retained no-LLM fallback.
The source snapshots preserve extraction inputs and recipes; no new LLM service is added.

The handoff targets Module 11 Iteration 1 and exports NewsSignalProvider and
EstimatedNewsSignalProvider with default HOLD, execution DISABLED and promotion
NOT_AUTHORIZED. Real backtests still require eligible historical news, independent
later evidence, execution/risk assumptions, short/inventory constraints and comparable
capital/fees/opportunity sets. Explanations do not bypass these requirements.

Limits are ten adversarial cases, 512 rule decisions, 32 held-out opportunities, eight
evaluation news snapshots, 128 observations, 20,000 price bars, 352 prefix snapshots,
512 extraction records, 64 MiB per file and 128 MiB total bundle. Prior news, event-study,
model, replay and execution schemas remain compatible. No migration or new third-party
dependency is required. See [ADR 0027](adr/0027-news-explanations-and-frozen-adversarial-evaluation.md).

Final validation passes **859 offline tests in 28 files**, including 38 new tests,
plus 28 isolated PostgreSQL tests, doctor and frozen offline installation. Full-fixture
CLI run/verify/report/reproduce yields byte-identical 108 indexed files plus bundle
metadata across three roots. Prior news, research, model, market and replay artifacts
verify unchanged. Final local bundle:
`data/news-audit/news-audit_a47e94ca91e487497d3a342dd3fc02c2fe0a32ade9855c73ce456da53c3d412c/`.
Exact acceptance records are in `data/news-audit/handoff-summary.json`.
