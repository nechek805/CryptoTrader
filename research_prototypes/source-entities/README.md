# Detached multilingual entity prototype

Module 16 Option D, fixture-only. Run `pnpm prototype:entities`. No network, article
collection, model training or execution. Inputs require origin SYNTHETIC and execution
DISABLED; the prototype is not exported by any production package or imported by apps.
Its separate local schemas may not silently become canonical master contracts.

The matcher receives no evaluation labels. Alias/article availability gates precede
matching; ambiguous aliases abstain and script confusables are preserved. Exact token
matching still fails on common nouns and company names. The independently passed labels
deliberately retain those false positives. Malicious prose may mention an asset but cannot
create a command, trade, credential read or provider request. Output contains source/version
hashes and candidate symbols, never factual confidence or directional profit probability.

All examples/labels are locally authored fiction. Fixture precision/recall do not estimate
real-corpus performance. Decision: DEFER. RFC 0016 and docs/module16-decision.md record
the required future contract, licensing, null-control and new-experiment work.
