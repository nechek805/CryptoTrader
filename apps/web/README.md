# @crypto/web

Module 14's authenticated Next.js research console covers overview, paper runs, versioned
news provenance, virtual trades, comparisons and operations. Every balance is SIMULATED.
The browser consumes validated backend data; no strategy or portfolio accounting runs here.

Run `pnpm dashboard` from the repository root for the local synthetic workspace on
127.0.0.1:3100, with API 3101. Run `pnpm web:build` for a production build.
See [dashboard and operator playbook](../../docs/dashboard.md) for roles, artifacts,
deployment/TLS requirements, controls, backups and limitations. Nothing is published.
